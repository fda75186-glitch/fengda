# 星系美术纹理 · 预览版 3

文件：`galaxy-reference-v3.png`。

制作方式：内置 image_gen 图像生成工具，按用户提供的星系参考图生成原创美术纹理，保留暖白核心、褐色尘埃、蓝紫旋臂和嵌入星团。随后接入三维体积着色器，支持改变角度与缩放；并非实拍仙女座照片或精确观测重建。

最终提示词：生成一张正上方、正交俯视、居中、完整可见的旋涡星系透明纹理。使用参考图的暖白金色核心、深褐色分叉尘埃带、白色星团、蓝紫色旋臂和柔和星云质感。核心约占星系直径 8–10%，保留周围颗粒与尘埃细节；主要旋臂伴随不规则次级云丝，外缘平滑淡化到透明。无文字、无界面、无行星、无实心背景、无倾斜透视，供程序映射到有厚度的三维星盘后再倾斜展示。

1254 × 1254 RGBA PNG，未修改像素，直接用于本地模型。各层体积的深度、整体倾斜、星空背景和自动转动由项目代码完成。
