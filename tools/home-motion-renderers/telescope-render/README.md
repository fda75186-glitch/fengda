# 第一人称望远镜推进素材（CG 备选）

此文件夹只是制作影片的独立渲染工具，不改变星语网页，不启动服务，不发布。

- `dist/` 已构建，base 为 `/telescope-camera-render/`。复用已有静态预览服务，挂载这个独立子目录后，用 `/telescope-camera-render/index.html` 打开。
- 点击「开始录制 8 秒」后，工具以 `canvas.captureStream(30)` 和 `MediaRecorder` 录制 1920×1080 WebM，完成后显示下载链接。
- 点击「预览运镜」播放一次；点击「回到开始」恢复起始帧。工具栏不在录制内容中。
- 结尾可在剪辑工具中倒放，用作退出目镜和返回地面的衔接。

摄像机使用固定 42° 视场角，位置从 `(0.08, 1.57, 0.30)` 米移动至 `(0, 1.54, -0.012)` 米。前约 2 秒视线向目镜光轴平移，随后约 6 秒推进进入橡胶眼罩。近景器材与远处草野视频有实际深度差。起点目镜约占画面高度 40%，画面不包含程序生成的灰色地板或硬边山脊。眼罩、机加工滚花、金属螺丝、90°天顶镜、双速对焦器、灰白折射镜筒、寻星镜、赤道仪和三脚架均为分别建模的三维几何。无人物脸、第三人称摄像机或塑料圆柱手臂。

末尾月轮位于黑色光学视野中，高度约为画面的 25%，适合接 NASA 的远距离月球接近镜头。月轮纹理取自 [NASA SVS 4619《Tour of the Moon》](https://svs.gsfc.nasa.gov/4619/) 的第 5 秒；不是发光屏幕，材质不向器材投光。

这是 CG 渲染，不得描述成实拍。尚未通过观看渲染画面判断写实程度；制作人应优先使用质量更高的实拍片段。构建成功只表明代码能够打包，不代表用户审核通过。

构建使用现有预览版 2 的 Three.js 和 Vite 依赖；配置中的绝对路径是此电脑的开发环境路径，工具不属于最终源码启动依赖。
