# 此渲染工具的素材构成

- 前景器材和摄像机：本项目程序生成的 3D CG。黑色橡胶眼罩、机加工金属目镜、90°天顶镜、双速对焦器、折射镜筒与支架分别建模。
- 远景草野和天空：Pavel Danilyuk 的 [Pexels 9121273《A Person Using a Telescope》](https://www.pexels.com/video/a-person-using-a-telescope-9121273/)。根制作人从实拍画面右侧裁出无人的草野与天空，调为较暗的蓝色夜景，生成 8 秒 H.264 文件。本工具将该实拍剪辑作为远距离 VideoTexture，保持 16:9 比例，并由景深效果虚焦。来源许可参照 [Pexels License](https://www.pexels.com/license/)。
- 黑色光学视野中的月轮：NASA SVS [4619《Tour of the Moon》](https://svs.gsfc.nasa.gov/4619/) 干净无标注素材第 5 秒的帧。月轮不向器材投光。

最终效果是「实拍远景 + 近景 CG 摄像机推进」，不得宣传为完整实拍或 NASA 拍摄的地面镜头。
