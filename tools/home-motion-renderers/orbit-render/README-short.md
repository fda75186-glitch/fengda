# 单个连续月球镜头 · 10 秒

对应用户修订：月球只出现一次，缩短月球段，取消画线/标注片段。

轨迹：0–2.5 秒摄影机沿真实空间路径从 9.2 Moon radii 推进到 2.68，初始月輪约占画面高度 27%，纬度固定 0.21 radians。2.5–10 秒摄影机绕静止月球完整 360°，半径、高度和 bank 仍按原镜头变化。推进到绕行以 smoothstep 缓速衔接，摄影机起止速度平滑。10 秒完成一周后直接结束，不追加后撤、停留或第二个全月镜头。

月球模型、NASA LROC 8K 颜色、LOLA 高程/法线、材质、灯光、固定世界星空和地球远景均复用原素材。Earth 保持原固定位置，本段不刻意切出第二段月球。没有经纬网、路线、画线或文字标注。关于数据许可与来源见 `SOURCES.md`；其中旧 17 秒时间说明属于历史记录，以本文件为准。

输出 1920×1080、30 fps、16:9、10 秒，无声。“开始录制”使用实时 MediaRecorder，制作时保持可见前台；录制结束提供“下载绕月影片”。“逐帧导出”保留为备用工具，固定 300 帧。

`build/` 路径 base 为 `/moon-single-render-v3/`，根代理可以复制到既有 50245 服务器对应子目录，打开 `/moon-single-render-v3/index.html`。未启动后台服务、未修改网站、未发布。
