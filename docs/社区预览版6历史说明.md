## 本版功能

默认显示 60px 的土星 Logo 按钮。鼠标或笔悬停、键盘焦点进入时展开，离开后收起。点击 Logo 会展开并保持；再次点击 Logo、点击空白处或按 Esc 收起。点击展开后的“问问星语”进入 AI 页面。

展开的背景从 Logo 旁伸出，Logo 自身位置不动；根据可用空间选择展开方向，避免超出屏幕。可拖动 Logo 或展开后的拖动把手移动，拖动不会误触打开。隐藏及土星 Logo 恢复入口继续保留，沿用位置和隐藏状态存储。遵守减少动态效果偏好。全站共用同一个悬浮组件，各页面交互一致。

本次将全站 AI 悬浮快捷入口默认收起为一个土星 Logo；鼠标悬停或点击后才展开快捷操作，继续支持用户拖动位置、隐藏和恢复。保留前版桌面端社区右侧整栏 sticky 跟随滚动、避开顶部导航、过长内容在栏内滚动，以及帖子卡片连续展开与收回。首页影片、探索宇宙三维模型、社区发布与登录等功能保持不变。动画表面从完整原卡片的实际边界连续移动并改变尺寸；内容按相同比例缩放，不再横纵向挤压。收回使用原卡片的实际画面作为终点，稳定滚动条宽度、阅读滚动位置和焦点，避免最后一帧跳动。卡片表面始终不透明，内部的列表与详情排版平滑衔接。展开途中关闭会沿当前进度反向返回；支持关闭按钮、Esc 和外部点击，并遵守减少动态效果偏好。

- 社区采用单列帖子流与右侧话题、社区面板，支持图文、长文章、视频内容。
- 顶部为左侧土星标志与导航，右侧发布入口和账号登录。
- 用户名、密码注册和登录由后端验证；可以发布帖子、评论、点赞并删除自己的帖子。当前账号和帖子存储在这一版独立的本地 SQLite，不是浏览器内伪登录。
- 发布页分为图文、文章、视频三个选项，右侧即时预览，可选择关联社区和话题。图片最多 9 张，每张最大 8 MiB；视频 MP4/WebM 最大 50 MiB。
- 草稿保存到当前浏览器的 IndexedDB，跨浏览器不会自动同步。私密帖子及其附件只允许作者账号读取。
- 保留约 31 秒首页影片、探索宇宙三维天体与其他既有科普页面。影片和素材说明见 `docs/首页影片剪辑说明.md`。

## 当前预览范围

本次开发预览 API 只绑定本机 `127.0.0.1`。同一 API 服务下的本机浏览器可看到彼此发布的公开帖子，账号重新登录仍属于同一个作者。**这一版尚未部署成跨设备公网社区或公网账号系统。** 既有线上共享服务没有更新。

普通完整启动包使用同版本的内置本地 API 与独立 SQLite，数据在该版本运行目录保存，不会带走开发预览中的账号、密码、令牌、数据库或用户上传附件。不同电脑分别启动各自的包时，各自拥有独立数据，不会自动互相同步。

要让不同电脑真正通过公网共享，应先由用户人工确认这版，再部署 `backend/` 中的云端 API，并配置 GitHub Pages 前端连接该公开服务。手工部署源码说明在 `backend/README.md`；本次没有执行云端部署或 GitHub 推送。

## 自行打开完整启动包

完整解压后保持目录结构，用户自行双击 `启动星语.cmd`。启动器从当前目录读取 `dist/`、`runtime/node.exe` 和 `backend/`，在本机创建账号/帖子数据并代理 `/api/*`。无需安装开发依赖。程序仅在用户自行运行时启动，制作过程没有自动运行交付包。

首次启动的科普示例由“星语编辑”展示，点赞和评论为 0；它们有示例标记，不代表真实用户活动。用户注册后可以自行体验发布、评论和点赞。当前没有邮箱找回密码或身份验证功能。保留该版本的数据目录才能继续使用本地账号。

## 从源码启动

需要 Node.js 24 和 pnpm 11。项目根目录运行：

```powershell
pnpm install --frozen-lockfile
```

在一个终端启动本地 API，数据目录需明确选择自己的新目录：

```powershell
node backend/dev-server.mjs --port 0 --data-dir "C:/your-preview-data" --assets-dir "C:/your-project/public/images"
```

API 会打印实际本机地址，例如 `http://127.0.0.1:51234`。在另一个终端设置该地址并启动网页：

```powershell
$env:VITE_COMMUNITY_API_URL = "http://127.0.0.1:51234"
$env:VITE_COMMUNITY_MODE = "preview"
pnpm dev
```

访问 Vite 打印的地址。后端使用 Node 内置 SQLite 与文件系统，无需额外 npm 依赖。关闭 API 所在终端会停止账号/发帖服务。

构建自包含启动包使用同源 API：

```powershell
$env:VITE_COMMUNITY_API_URL = "/"
$env:VITE_COMMUNITY_MODE = "preview"
pnpm build
```

`dist/` 是静态构建产物。单独运行 `pnpm preview` 只提供静态网页，不会自动启动本地 API；体验账号和发帖应使用上述独立 API 配置，或由用户自行运行交付包的 `启动星语.cmd`。

## 文件与数据

- `src/`：Vue 页面、账号、发布、草稿和社区交互。
- `backend/`：共享业务实现、本地 Node/SQLite 适配器、Worker D1/R2 适配器、迁移、测试及部署源码说明。
- `public/`：影片、纹理、图片和标志；`docs/`：来源、版本和制作说明。
- `tools/`：影片制作源与必要运行纹理，普通网页启动不需执行这些工具。
- `runtime/node.exe`、`launch.mjs`、`启动星语.cmd`：完整启动包的自包含本地入口。

本机运行数据不包含在交付 ZIP 中。草稿保存在浏览器，账号和帖子由当前本地 API 的 SQLite 保存。私密附件使用授权读取；不能把账号令牌放入媒体网址或源码。
