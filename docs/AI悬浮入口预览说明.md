# 社区与发布 0.1.3 预览版 6

版本号 `0.1.3-preview.6`。在首页精简预览版 3 上继续制作，保留 31.07 秒影片与探索 3D；已确认正式版仍为 0.1.1。

默认显示 60px 的土星 Logo 按钮。鼠标或笔悬停、键盘焦点进入时展开，离开后收起。点击 Logo 会展开并保持；再次点击 Logo、点击空白处或按 Esc 收起。点击展开后的“问问星语”进入 AI 页面。

展开的背景从 Logo 旁伸出，Logo 自身位置不动；根据可用空间选择展开方向，避免超出屏幕。可拖动 Logo 或展开后的拖动把手移动，拖动不会误触打开。隐藏及土星 Logo 恢复入口继续保留，沿用位置和隐藏状态存储。遵守减少动态效果偏好。全站共用同一个悬浮组件，各页面交互一致。

本次将全站 AI 悬浮快捷入口默认收起为一个土星 Logo；鼠标悬停或点击后才展开快捷操作，继续支持用户拖动位置、隐藏和恢复。保留前版桌面端社区右侧整栏 sticky 跟随滚动、避开顶部导航、过长内容在栏内滚动，以及帖子卡片连续展开与收回。首页影片、探索宇宙三维模型、社区发布与登录等功能保持不变。动画表面从完整原卡片的实际边界连续移动并改变尺寸；内容按相同比例缩放，不再横纵向挤压。收回使用原卡片的实际画面作为终点，稳定滚动条宽度、阅读滚动位置和焦点，避免最后一帧跳动。卡片表面始终不透明，内部的列表与详情排版平滑衔接。展开途中关闭会沿当前进度反向返回；支持关闭按钮、Esc 和外部点击，并遵守减少动态效果偏好。 原有单列社区、话题面板、注册登录和图文/文章/视频发布继续保留。图片最多 9 张、每张最大 8 MiB；视频 MP4/WebM 最大 50 MiB。草稿保存在本机浏览器 IndexedDB。公开帖子可在同一个本机预览 API 的浏览器间共享，私密帖子及附件只允许作者读取。

账号、帖子和媒体由独立本地 SQLite/文件 API 保存；源码同时包含 Worker D1/R2 云端适配器。当前没有部署公网账号或跨设备共享新版社区。正式上线需先人工确认，再部署后端并更新 GitHub Pages 前端。旧线上共享服务、已采用网站和历史版本全部保留。

此目录仅供人工审核，未发布或安装，没有自动启动交付包。完整包不包含开发数据库、用户账号令牌、已上传用户附件或本机端口/日志。页面界面由用户人工审核。

详细 API、鉴权、媒体和手工部署契约见 `../backend/README.md`；本次只使用本机独立 SQLite 预览服务，不代表公开部署。
