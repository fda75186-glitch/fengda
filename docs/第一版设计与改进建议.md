# 星语第一版：设计与方案修订

## 第一版范围
依据用户提供的 v3 方案制作 Vue 3 + Vite 可运行前端；面向大众与学生，通俗易懂。完成首页、内容库与详情、AI 助手离线演示、知识卡工作室、太阳系互动图谱、测验、观测地点导览与个人收藏。社区、账户认证和管理后台留到后续版本，避免空入口。AI 演示采用本地知识检索，明确标记，不宣称真实大模型接入。收藏和学习进度保存在本机浏览器。

## 对照所附赛道截图的修订
- 截图强调 AI 是应用核心、避免简单 API 调用；建议主线为“提问 → 有来源的知识解释 → 对应图谱 → 测验 → 个性化下一步”。后续实现 RAG、年龄适配、多轮上下文、工具调用和回答引用。
- 已读截图省赛评分中 AI 技术深度占 35%。优先投入可证明的 AI 学习体验，社区和 CRUD 后台不是截图规定的必备功能。
- 截图列明省赛报名与作品提交截止为 2026-11-18，反馈预计 2027 年 1 月底；原方案中的“省赛 11 月、国赛 12 月”不能直接沿用，校内截止需向学校另行确认。
- 截图演示视频要求 5–8 分钟、MP4、至少 1080p，原方案的 3–5 分钟需修订。
- 提交材料包括保留 Git 历史的代码仓库、README、依赖与环境模板，以及不超过 30 页的技术 PDF。
- 地图观测地与真实天空星图拆开：第一版为地点概览与太阳系示意。真实星图后续需要时间、地点和天体坐标计算，不能把装饰性星空标为准确观测数据。
- AI 生成文本不等于 AI 生成图片。第一版知识卡重组已校验的本地内容；后续图像生成应单列能力，并标注艺术想象与真实观测图。
- NASA 图片需逐张保留来源和完整署名；不能把“非商用”当作通用版权豁免。

## 视觉约定
参考用户方案的“先空间后细节、左右联动、主题分类、图片优先”。首页不用自动轮播，保留一个大幅土星主题；深墨色背景、暖白文字、薄边框、青绿色动作。主动作是开始探索，次动作是向星语提问。桌面两栏，移动端单栏与横向主题筛选。所有重要按钮都有可见标签，弹窗可用 Escape 关闭。

## 后续建设优先级
1. FastAPI 服务端代理 DeepSeek，密钥只在服务端环境变量中。
2. 可信来源内容库 + RAG，段落级引用、未知问题拒答、区分事实与假说。
3. AI 依据问题选择行星对比、时间线等工具；按学习水平解释并生成相关题目。
4. 用户账户与云端学习记录、真正的每日推荐。
5. 社区、审核和后台；再做语音与真实位置星图。
