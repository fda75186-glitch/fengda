# 0.1.7-preview.5：宇宙地图与虫洞穿越

## 交互约定

沿用既有 AR 场景的深蓝、灰蓝、暖金配色、边框和字号层级，参考现有飞船界面与用户此前的宇宙参考图。宇宙地图的任务是总览、逐层选择、搜索和快速前往，主操作为“快速穿越”。替换窄侧栏列表，使用占据主要视野的地图：宇宙全景、七层尺度入口、区域天体分布、目的地简介。小屏保留地图，目录置于上方可滚动区域，地图标签按实际像素布局。

地图提供拖动平移、鼠标位置缩放、缩放与重置按钮、键盘选择、Escape 关闭、焦点约束及返回原触发按钮。打开地图暂停当前飞行，关闭恢复原暂停状态，选定目的地后结束自动游览并前往。加载中、目录失败重试、搜索无结果均有状态文案。先选择天体，可查看简介与展开下一层，再决定穿越；无需提前改变飞船位置。

## 地图内容

保留地球发射场、地月系统、太阳系、恒星邻域、银河系、本星系群、宇宙网七层。宇宙全景为尺度导航图，区域地图显示所有已有目的地；NASA 快照的 4,842 个系统可搜索并逐个生成地图，太阳系 29 个天体仍保留。地图不是完整可观测宇宙的测绘，也没有虚构未知系统；位置和尺度继续采用科普示意并在页脚注明。

## 穿越效果

远距离同区域航线、跨区域转移开启科幻虫洞效果：入口扩展、透视隧道光环和加速星光、减速驶出。普通远程穿越约 4.8 秒（受速度选项影响），快速近距离驶近约 2.4 秒。目标位置仍使用既有完整船体安全包络与避障路径，抵达后显示选中天体资料。

地表出发必须先完成原有垂直起飞流程，不能用虫洞跳过发射场。近距离移动和重置视野不强制播放虫洞。暂停冻结穿梭进度；手动接管取消当前效果与自动抵达。减少动态偏好下取消隧道纹理流动并降低强度。虫洞只额外绘制一个全屏着色器平面，在驾驶舱之前绘制；提前编译并在离开 AR 场景时释放。

## 验证

78 项纯 Node 逻辑测试及 Vite 构建通过：七层地图的目的地映射、全部 4,842 系统生成、缩放锚点与边界、远近路线识别、虫洞强度连续与减少动态、资源释放、跨区域到达指定行星、暂停与手动取消，以及既有导航/碰撞/社区逻辑。

按用户约定不做自动 UI 审核，不运行浏览器截图或 GL 像素测试，未测实际 GPU/FPS。地图排版与虫洞视觉待用户人工预览。正式 0.1.6、交付 ZIP 和公网均未更新。
