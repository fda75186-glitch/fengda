# 星语第二版 0.2.0

保留第一版，第二版独立存放在桌面传智杯。按用户要求由用户人工审核界面。

- 全站方框按压按钮，移除箭头装饰；展开式全站搜索。
- 探索宇宙使用可拖动、缩放的 Three.js 天体模型。
- 首页原创三维观星旅程：地球上的爱好者与望远镜、进入目镜、环绕月球、返回地球。
- 社区改为宽信息流与右侧话题栏，支持发布观测话题与照片；知识问答属于社区。
- 共享社区使用独立 Worker API、D1 与 R2；GitHub Pages 托管前端。
- 天文地标点击直接展示历史与科普资料；地图添加本地地理数据备用显示。

社区 API： https://xingyu-shared-community.aptbook6.chatgpt.site
GitHub： https://github.com/fda75186-glitch/fengda

模型是科普展示，不按真实距离比例；月球纹理来自 NASA SVS CGI Moon Kit，地球纹理来自 NASA Blue Marble。
