# 知识卡制作与社区分享（0.1.9-preview.4）

## 本次修复

用户确认原问题是“AI只回复文字，没有生成知识卡”。此前普通Agent请求使用tool_choice:auto，模型可自行选择直接回答；前端只要收到非空文字就认为该轮完成，因此生成意图没有被落实为可用卡片。

现在明确的知识卡制作请求进入共享的制卡流程：服务端检索站内资料、读取最多两篇原文，再按腾讯官方协议指定create_knowledge_card工具。返回结果必须包含有效卡片和真实资料ID，才能向客户端发送action和done。只返回文字、错误工具、缺字段或伪造资料都不能显示制作成功；字段校验失败最多修正一次。取消、账号鉴权、60秒期限、速率和日额度限制继续生效。原普通问答和其他工具流程保留。

知识卡工作室通过结构化task（kind/topic/level）调用同一Agent接口；AI对话识别明确制卡意图进入同一流程。教程、否定请求、知识卡封面生图仍走原对话。主题、深度和sourceIds均有服务端校验，不接受代码、URL、任意操作或发布指令作为任务参数。

腾讯工具选择协议：https://cloud.tencent.com/document/product/1823/135872
实际模型hy4-preview，thinking.type=disabled；使用tool_choice指定函数对象，parallel_tool_calls=false。

## 站内联动

- AI对话收到完整知识卡后，同步到知识卡工作室；点击“在工作室查看”展示同一张卡，主题/阅读深度同步，不二次生成。
- 工作室和AI对话卡片均提供“分享到社区”。从点击的按钮展开分享窗口，沿用原有展开/收回动画和减少动态偏好。
- 分享窗口自动填入知识卡标题、导语、全部要点、补充事实及真实参考链接，以Markdown社区文章发布，保留AI辅助制作说明。用户可修改正文、分类与可见范围，再检查并确认发布；不需要另行复制粘贴。
- 同时要求“制作知识卡并分享到社区”时，返回该卡及由同一内容转换的社区草稿，不另写一篇不同文章，也不自动发布。卡片和草稿共用确认标识，显示键包含类型，避免Vue重复key。
- 发布结果显示“已发布”和查看入口。相同账号下，同一张卡在AI对话/工作室/分享窗口使用相同幂等标识，重复点击不重复发帖。关闭再打开保留当前会话的分享草稿及已发布结果。
- 也可进入完整发布编辑器补图；此前编辑内容先存草稿箱。分享在退出/切换账号后关闭并清空；异步发布结束时再次校验账号与会话，不把结果展示给另一个账号。
- 旧本地知识卡的来源也从站内目录重建，不信任任意本地URL。原收藏与Markdown导出保留。
