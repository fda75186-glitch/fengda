# 0.1.9-preview.2 · 星语站内工具助手

基线为正式0.1.8，保留0.1.9-preview.1已接通的腾讯混元Hy4问答。本版仍仅本地预览，未更新公网、正式目录和交付ZIP；等待用户人工确认，不自动UI/浏览器/GL审核。

## 可用功能

| 用户请求 | 实际行为 |
| --- | --- |
| “制作一张土星光环知识卡” | 模型检索/阅读站内资料，调用工具输出结构化知识卡。对话里可收藏、导出Markdown、转入工作室。工作室制作按钮也已接真实AI。 |
| “把刚才的卡片写成社区文章并发布” | 模型生成可编辑文章，显示分类、公开/私密、AI辅助声明。用户检查并勾选确认后，应用用当前账号真实调用现有社区接口；模型不直接发帖。 |
| “给文章加照片/发布视频” | 转入现有发布编辑器，由用户选择本机素材并确认发布。不会捏造照片、视频或用户观测经历。原编辑草稿先保存，保存失败不覆盖。 |
| “打开天文挑战/我的星空/探索宇宙” | 生成站内操作按钮，点击后打开真实页面。 |
| “阅读并收藏月相知识” | 可打开真实知识卡、收藏文章；重复收藏不反向取消。 |
| “定位中国天眼FAST” | 点击操作按钮后进入观测指南，并选择对应观测站。 |
| “比较行星大小/距离/公转周期” | 打开图谱的对比模式并选中相应指标。 |
| “探索土星/银河/宇宙网” | 启动原有3D航行，并调用原航线与避障逻辑驶向目录目标。不会由模型修改轨道坐标。 |
| “探索TRAPPIST-1系统” | 打开AR并在NASA快照中核实精确系统名，存在才航行；不存在明确提示，可继续地图搜索。 |
| “搜索社区话题/打开刚发布的内容” | 检索最多120条近期公开帖子中的匹配内容，或打开当前用户有权限查看的指定帖子。不会把其他账号的私密帖子交给模型。 |

AI不是系统管理员：账号登录、相机/麦克风授权、选择本机文件、删除内容和付费操作仍由用户完成。当前没有AI生成图片/视频、联网搜索或实时天气能力，不能宣传为无边界地执行任意操作。

## 工作流与边界

- `/api/ai/chat`保留普通问答兼容；新增登录鉴权的`/api/ai/agent`，共用已有额度/并发/取消/超时限制。
- 模型通过官方Function Calling请求`search_site / read_knowledge / create_knowledge_card / draft_community_post / site_action`。站内检索是词法检索增强，未声称向量数据库或联网RAG。
- 每任务最多4轮模型请求、6次工具执行、4张操作卡，整体AI操作60秒期限。复杂任务超过预算会明确提示拆分，不声称执行成功。
- 工具白名单和字段约束由`shared/assistant-tools.mjs`统一定义；服务端及浏览器分别校验。模型不能指定任意URL、脚本、SQL、账号、API Key、模型服务地址或确认权限。
- 知识卡引用只能用本轮已检索/读取的站内ID；真实来源链接与封面由应用根据目录重建。无参考来源明确标注待核实，不伪造引用。引用不是对模型所有表述的事实背书。
- 社区生成仅准备草稿，确认发布由独立用户事件触发。草稿绑定生成时的账号；上传和提交期间账号/会话变化则停止后续提交。会显示纯文字/无配图及AI辅助声明。
- 发布确认ID通过现有HTTP接口的`Idempotency-Key`传入，服务端按账号派生稳定帖子ID并校验内容一致性。相同确认重试不生成重复帖子；同一确认改内容返回409。没有数据库迁移或删除用户数据。
- 对话与草稿操作在站内跳转期间保留于页面内存，退出登录/换账号清除AI会话；刷新网页不保证恢复AI对话。转入编辑器后的草稿由现有IndexedDB草稿箱保存。

## 验证

2026-10-15，真实Hy4一次组合任务依次执行：两次站内检索、两次阅读、知识卡生成、社区草稿生成，收到两张有效操作卡及最终done，约49.8秒。知识卡引用NASA Space Place土星环与NASA卡西尼资料；确认前独立测试数据库帖子数为0。没有向实际用户社区发布测试帖。报告在工作区`output/ai-agent-live-check.json`，不含密钥。

前端113项、后端32项，共145项纯Node测试通过，Vite构建通过。纯Node测试覆盖多轮工具回填、SSE参数分片、真实来源校验、拒绝未知工具/外部目标、工作流上限、私密帖子排除、账号切换、显式发布确认及重试去重。未自动打开网页检查UI或GL画面，交互与视觉由用户预览确认。

接口依据：[腾讯官方流式工具协议](https://cloud.tencent.cn/document/product/1823/135872)、[腾讯官方思考模式](https://intl.cloud.tencent.com/zh/document/product/1300/80637)。后续上线必须同时部署前端、共享后端和新增shared模块，并通过云端Secret配置腾讯凭据；本机私密文件不得进入分享包或Git。
