# 观测指南地图数据来源

核实日期：2026-10-10。地图采用 MapLibre GL JS 6.13.0、真实 OpenStreetMap 底图和 Mapterhorn 数字高程数据。默认倾斜58°，可平移、旋转、缩放、切换二维和三维；选中地点会飞行到该地点。没有用示意中国轮廓或随机坐标替代地图。

## 坐标与精度

## 地图实现与归属

- [MapLibre 官方3D地形示例](https://maplibre.org/maplibre-gl-js/docs/examples/3d-terrain/)证明 raster-dem、terrain、倾斜与旋转能力。[Map API](https://maplibre.org/maplibre-gl-js/docs/API/classes/Map/)用于 flyTo、fitBounds、setTerrain 与 resize。[Marker API](https://maplibre.org/maplibre-gl-js/docs/API/classes/Marker/)用于地理标记。
- v6 的 Worker 采用[官方 Vite 安装说明](https://maplibre.org/maplibre-gl-js/docs/)中的 `?worker&url` 与 `setWorkerUrl()`，避免开发和构建后 Worker 路径丢失，确保 DEM 解码工作实际运行。
- 底图：`https://tile.openstreetmap.org/{z}/{x}/{y}.png`；保留 `© OpenStreetMap contributors` 归属并链接到[版权与 ODbL 说明](https://www.openstreetmap.org/copyright)。遵循[瓦片服务使用政策](https://operations.osmfoundation.org/policies/tiles/)，浏览器按可见区域请求，不做批量预下载，不禁用 HTTP 缓存。
- 地形：`https://tiles.mapterhorn.com/tilejson.json`。开发时直接读取服务 TileJSON，确认 `encoding=terrarium`、`tileSize=512`，防止错误编码产生虚假山峰。terrain 与 hillshade 各用独立 source，真实高程比例 `exaggeration=1`。
- Mapterhorn 的[官方覆盖说明](https://mapterhorn.com/)说明全球30米高程；更高分辨率只覆盖部分地区，中国大陆此处使用全球覆盖。保留 `© Mapterhorn` 并链接到[高程数据归属页](https://mapterhorn.com/attribution/)。山地可见起伏，上海、北京的平坦地形如实显示，不人为制造山峰或虚构建筑。

## 加载与恢复

只有收到 OSM 已加载瓦片的 sourcedata 事件才显示地图就绪，不把 style load 等同于底图成功。初始加载超过18秒显示失败与重试；离线显示状态，恢复联网会重新初始化。高程加载失败会明确提示二维降级，保留真实底图；瓦片部分错误显示不完整提示和重试。WebGL 初始化失败显示错误而不伪造成功。任何状态都能从地点资料打开原始 OSM 地物和官方场馆信息。

在线瓦片服务的可用性取决于网络和提供方。当前是无需密钥的开发预览接入；公开部署前应按预期流量选择服务或自建缓存，不声称包含百度地图的城市三维建筑数据。

## 验收

1. 打开观测指南，看到有道路、地名的真实地图以及默认兴隆的山地。
2. 点击四个地点卡片，地图移动至对应经纬度，详情与高亮同步；重复点击当前地点也能回到它。
3. “全部地标”包含四个地点；“定位此处”回到当前地点；2D/3D、右上角缩放/朝北控制有效。
4. 右键拖动旋转和倾斜；触屏用两指操作；滚轮仅在按Ctrl时缩放，不阻止整页滚动。
5. 断网或拦截底图/DEM请求时出现明确状态和恢复按钮，地点资料仍可使用。
6. 320px、768px和桌面尺寸没有地图溢出，标记与工具栏可用键盘操作，版权可访问。
