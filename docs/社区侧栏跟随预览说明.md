# 社区与发布 0.1.3 预览版 5

版本号 `0.1.3-preview.5`。在首页精简预览版 3 上继续制作，保留 31.07 秒影片与探索 3D；已确认正式版仍为 0.1.1。

本次调整桌面端社区右侧整栏：使用 sticky 跟随页面滚动，让侧栏持续可见，顶部留出 80px 导航所需空间；内容超过可用高度时，可在侧栏内部滚动。首页影片、社区发布与登录等功能保持不变。前版帖子卡片的连续展开与收回动画继续保留。动画表面从完整原卡片的实际边界连续移动并改变尺寸；内容按相同比例缩放，不再横纵向挤压。收回使用原卡片的实际画面作为终点，稳定滚动条宽度、阅读滚动位置和焦点，避免最后一帧跳动。卡片表面始终不透明，内部的列表与详情排版平滑衔接。展开途中关闭会沿当前进度反向返回；支持关闭按钮、Esc 和外部点击，并遵守减少动态效果偏好。 原有单列社区、话题面板、注册登录和图文/文章/视频发布继续保留。图片最多 9 张、每张最大 8 MiB；视频 MP4/WebM 最大 50 MiB。草稿保存在本机浏览器 IndexedDB。公开帖子可在同一个本机预览 API 的浏览器间共享，私密帖子及附件只允许作者读取。

账号、帖子和媒体由独立本地 SQLite/文件 API 保存；源码同时包含 Worker D1/R2 云端适配器。当前没有部署公网账号或跨设备共享新版社区。正式上线需先人工确认，再部署后端并更新 GitHub Pages 前端。旧线上共享服务、已采用网站和历史版本全部保留。

此目录仅供人工审核，未发布或安装，没有自动启动交付包。完整包不包含开发数据库、用户账号令牌、已上传用户附件或本机端口/日志。页面界面由用户人工审核。

详细 API、鉴权、媒体和手工部署契约见 `../backend/README.md`；本次只使用本机独立 SQLite 预览服务，不代表公开部署。
