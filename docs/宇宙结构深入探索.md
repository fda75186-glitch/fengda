# 0.1.8-preview.2：修复宇宙网远景不可见

用户截图确认预览.1的宇宙网过暗：世界尺寸投影在远景下限仅0.65个物理像素，椭圆核又比粒子本身窄；低透明度与缺失输出色彩转换叠加，导致仅剩微弱细点。预览.2为远处星系点保留2个CSS像素直径，小尺寸采用宽圆形剖面、接近后再显示椭圆/旋涡细节；随自适应分辨率和窗口尺寸同步。恢复星系示踪与弥散细丝亮度，加入Three.js输出色彩转换。保留正常透明混合与RGB上限，避免再次加色饱和成白块。不增加粒子数量和绘制批次。

新增纯Node投影回归覆盖桌面、截图近似尺寸、窄窗口与0.85/1/1.7渲染像素比，检查远景粒子可分辨尺寸、近景尺寸上限及着色器的小尺寸剖面与色彩转换。此检查不是浏览器/GL视觉验证，画面仍须人工确认。

以用户已确认的正式0.1.7为基线，只改本机预览目录，正式目录/交付包/公网不变。用户指出宇宙网白色团块、三角连线及内部无法探索。

## 渲染

此前星系团与宇宙网复用相同粒子连线模型，较大的加色星点在重叠区域饱和成白块。本版分开处理：宇宙网44,000个细星系示踪点和暗淡丝状背景，星系团14,000个成员示踪点；去掉三角骨架线。小光点包含椭圆/旋涡轮廓，限制屏幕尺寸，正常透明混合，RGB和透明度限制在有界范围，降低叠加过曝。结构布局与每一个背景点仍为科普采样。

室女座成员M87/M49/M60使用三维椭球恒星分布与平滑星晕；M90使用旋涡模型。背景点不产生标签，也不作为实体碰撞球，只有明确的交互节点可被选择。

## 深入路径

宇宙网 → 丝状结构内部 → 本星系群 / 室女座星系团。
室女座星系团 → M87 / M49 / M60 / M90 → 星系内部 → 恒星样本 → 四颗行星的科普示意系统。
本星系群 → 原银河系分层，或仙女座/三角座/大小麦哲伦云内部 → 恒星样本示意系统。

点击天体驶近后，资料里显示显著“进入…”按钮；也可双击可探索的三维结构/名称。宇宙地图的“展开区域”接入同一目的地解析，可连续展开，并通过“返回上层”回退。飞船进入星系后镜头从内部位置开始，保留原虫洞转移和净空检查。内部场景可用底部返回按钮返回父区域。

NASA原始目录保持独立的真实系统搜索；未把银河系内的TRAPPIST/Kepler等目录归属到室女座或仙女座。未知的内部恒星位置及示意行星在名称、简介和事实栏明确标注，不增加虚假的观测参数。
