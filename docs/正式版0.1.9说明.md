# 星语正式版 0.1.9

2026-10-15 用户人工确认采用 0.1.9-preview.4。本次仅采用和交付，公网仍为 0.1.8。

本版包含真实腾讯 Hy4 流式对话、站内工具、知识卡制作与社区分享。明确制卡请求会检索资料并生成真实知识卡，同步工作室。分享窗口自动填充卡片、参考来源及 AI 标识；用户编辑和检查确认后发布，重复确认不会重复发帖。保留既有宇宙探索、地图、社区、文章和动画。

真实 Hy4 已验证知识卡生成；隔离临时 HTTP 账号和数据库验证了确认前零帖子、确认后一个帖子、重复确认仍同帖。166 项纯 Node 逻辑检查（前端 123、后端 43）及构建通过。画面由用户人工确认，未自动 UI/浏览器/GL 审核。

图片生成入口和服务端接口已准备，但腾讯 hy-image-v3 权限尚未通过真实调用验证，保持关闭；不把图片功能标记为已开通。

完整文件包解压后手动双击“启动星语.cmd”；内置 Windows Node 运行时，启动本地社区及前端，不依赖作者预览服务。启动器仅由用户运行，交付过程没有运行或安装它。源码包不含构建文件或运行时，开发需安装 Node 24、按 pnpm 锁文件安装依赖并构建。构建本地使用 VITE_BASE_PATH=/、VITE_COMMUNITY_API_URL=/、VITE_COMMUNITY_MODE=preview。

队友使用 AI 需要自己的腾讯云 API 凭据：手动运行“配置腾讯AI.cmd”，在终端给出的本机配置页面填写自己的 Key、TokenHub 平台和已授权的模型（本机验证模型为 hy4-preview）。配置完成后重新启动本地服务。私密文件 .env.ai.local.json 只供服务端读取，不应提交、上传或分享；完整源码包开发时可用 node tools/configure-tencent-ai.mjs 配置。源码包不带 runtime/node.exe，因此配置脚本用已安装的 Node 运行。模型调用按腾讯账户实际计费，未配置时显示未配置状态。

两份共享 ZIP 均不含作者密钥、账号、数据库、上传媒体或运行日志。桌面正式目录为作者本机单独保留了当前实际社区数据与私密配置；旧正式版中不同的数据继续存入 runtime/preserved-data。不要直接压缩整个本机正式目录给别人，请使用已校验的两份交付 ZIP。

解压后启动的是独立本地社区，不会自动同步公共网站的帖子。未来公网 AI 上线须同时部署前端、后端与 shared 模块，并在云端配置 Secret；本次未推送、未更新公网。原预览仍可使用。
