# AI图片生成功能（0.1.9-preview.3）

入口：顶部「AI星语」→「AI宇宙绘画」，或右上角绘画按钮。也可以直接要求助手“生成一张土星的科普插画”，模型通过受限 prepare_image 工具准备可编辑的生图请求卡。

## 用户流程

1. 登录星语账号，输入画面描述（4–1600字），选择横图4:3、方图1:1或竖图3:4，以及写实宇宙插画、科普插画或天文海报风格。
2. 用户点击生成后才真实调用腾讯 Hy-Image-3.0，每次1张。模型调用与图片保存完成后显示预览；有等待、停止等待、审核失败、模型无权限、额度不足和检查本次结果状态。
3. 可以下载图片，或点「用于社区发布」。有未发布的AI文章草稿时携带该文与新图，否则准备一篇明确说明AI科普示意的配文。进入发布编辑器后用户编辑、选择可见范围并亲自发布。原编辑内容先存入草稿箱。
4. 生成结果由后端保存到当前账号的受保护媒体区，公开发帖后才可公开读取。最近12次生图记录按账号显示，完整页面刷新后可从记录重新查看。图片不会通过临时签名链接直接暴露给浏览器。

## 真实服务

接口固定为 POST https://tokenhub.tencentmaas.com/v1/wand/hunyuan-image/v3-generation ，模型 hy-image-v3。按腾讯官方同步文生图协议发送 prompt、size、footnote（星语AI生成）、revise:false。尺寸为1024x768、1024x1024、768x1024；图片为AI艺术/科普示意，不能作为观测证据。

腾讯官方文档：https://cloud.tencent.com/document/product/1823/135745
腾讯官方价格：https://cloud.tencent.com/document/product/1823/130055
参考费用0.2元/张（每张20,000tokens）；实际以腾讯控制台和账单为准。

现有Key此前只授权hy4-preview，真实调用返回401006（模型不在可访问列表）。用户已表示会自行登录并开通。控制台已定位并筛选hy-image-v3，已展示“启用后付费”确认框，由用户完成计费开通；最后读取服务仍未启用。真实端到端调用截至2026-10-15仍返回IMAGE_ACCESS，尚未生成真实图片。必须在在线推理→视觉模型开通Hy-Image-3.0，并将hy-image-v3加入现有Key访问范围；日Token上限须容纳单张20,000tokens及聊天用量。没有擅自修改云端权限、开通后付费或创建新密钥。

后端仍使用TENCENT_API_KEY私密配置；新开关TENCENT_IMAGE_ENABLED='true'由维护者在确认模型权限后开启。未配置开关时界面明确显示未开通，不输出假图。现有本机Key不写入VITE变量、源码、构建、文档、日志或交付包。

## 服务保护与集成

- POST /api/ai/images：鉴权、严格参数校验、UUID幂等标识。GET /api/ai/images/:id查询本账号任务，GET /api/ai/images读取最近12次记录。
- 同一请求ID不重复调用付费模型；重复、并发、失败后的同ID重试均返回原记录。原参数变化或跨账号重用被拒绝。另一次生成需用户明确点击。
- 每账号1次/分钟、5次/天；全站10次/天；进程/Worker isolate最多2个并行请求，D1/SQLite记录全站日额度。限额按尝试次数统计，非全局分布式并发锁。
- 单次最长180秒，客户端等待200秒。停止等待会尝试取消上游请求；腾讯已产生的模型用量可能仍计费，不自动重试。长时间失去进程的pending记录在240秒后转为超时失败。
- 仅下载官方文档中的HTTPS腾讯COS图像主机，拒绝跳转、其他地址、SVG/HTML、类型签名不符及超过8MB文件。不向图像CDN转发API密钥，不转发原始模型错误或签名URL。
- 新增0002_image_generations.sql迁移，仅加任务表和索引，不删除/更改既有用户记录。媒体仍使用已有BUCKET、media表与所有权校验。
- 社区编辑器保留图片文件用于浏览器草稿预览，发布时复用所属账号的媒体引用，无需二次上传；后端再次校验所有权。换账号或会话失效会停止/拒绝旧请求结果与发布。
