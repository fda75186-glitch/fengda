## 预览 3 修复

用户反馈资料卡从地图左侧出现。根因是全站按钮的 tap-feedback、active 缩放及 transform 过渡覆盖了地图标记定位用的 translate，随后读取到错误的名称边界。现在这三项都排除在线与备用地图标记，标记反馈仅改变名称的亮度和内阴影，不修改位置或尺寸。全屏动画容器和名称边界继续使用同一视口坐标系。

发展历程改为独立日期栏：年份一行，完整月日一行；月日不自动拆行，正文使用可收缩的第二列。保留原始史实字段与 ISO 日期语义。构建通过，没有进行自动 UI 审核，沿用当前预览目录与地址，尚未上线。

## 预览 4

此前标签避让逻辑会把已移出视野的站点名称强制夹回地图边缘，造成 FAST、北京等名称悬挂。现在先按真实图钉的屏幕坐标过滤视野外站点，再为视野内的名称处理重叠。地图平移、缩放、旋转和定位会同步更新可见性；备用图使用相同规则。站点重新回到视野时恢复显示，真实经纬度保持不变。

天文挑战作为探索宇宙的导航子功能：点击顶部探索宇宙进入该页面并展开子选项，点击天文挑战进入原 quiz 功能；挑战页标亮探索宇宙父项。桌面与移动导航均可打开、关闭和键盘操作。社区侧栏的原挑战入口移除，首页快捷入口保留。

仅更新同一预览目录，等待用户人工审核。没有发布公网或新建交付备份包。
