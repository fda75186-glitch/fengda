# 0.1.7-preview.4：发射场、总览与银河细节

继续在现有预览目录修改，正式版 0.1.6、两个交付 ZIP 及公网保持原状态。前端预览 （解压后手动启动，见打开说明.txt） ，从顶部 AR 宇宙云图进入。

## 本次修改

- 修正发射台钢板与混凝土共面的深度冲突，缩窄相互重叠的警示条；统一世界内置材质与全部自定义着色器的对数深度计算。地面阶段锁定地球球面精度，其余天体的精度切换增加滞回区间，避免临界距离反复切换。
- 地形细分从 64×64 提升为 128×128，并改为连续色调。增加总装厂房、分节卷帘门、屋顶设备、红色识别条、服务塔管线与楼梯、立式储罐、沿曲面铺设的运输道路和文昌基地场内标牌；仍为文昌风格的科普示意。设施碰撞范围从 5 组增加至 12 组，起飞路线继续检查船体净空。
- 行星系统总览由包围全部小天体的空间对角线，改为依据主要天体投影边界取景，并提高俯视角度。在横屏、竖屏和宽屏比例下检查主要行星完整入画且比旧取景更近。远端矮行星继续保留在航图中。
- 天体名称按选中目标、主要天体和小天体排序，依次在锚点附近寻找空位，避开页面控制面板；细线指向原天体位置。空间不足时隐藏次要名称，近景重新显示，全部目的地始终可从航图选择。
- 重做 AR 银河主体：主银河 64,000 颗细星点与三维核球，连续旋臂辉光、分支与深色尘埃带，银河中央恒星棒。多星系场景每个模型 18,000 星点；每个星系主体仅两次绘制。缩小概念性银河中心黑洞展示半径，避免遮盖整个核球。恒星位置、形态和亮度为程序化科普示意。

## 本次验证

71 项纯 Node 逻辑测试及 Vite 构建通过。新增覆盖不同画幅的总览投影、密集标签避让与边界、地面初始球面稳定性、全部自定义材质深度配置、银河真实三维点数据、层切换资源释放。既有起飞、改目的地、船体与相机碰撞、NASA 目录转换检查继续通过。

按照当前用户约定，没有自动 UI 审核，没有开启浏览器做截图或 GL 像素检查，也没有实际设备 GPU/FPS 测量。构建和逻辑测试不能证明视觉上已消除全部闪烁；实际画面与流畅度等待用户人工预览。

# 0.1.7-preview.3：从地表启航与航行优化

本次修改复用现有预览目录，以正式版 0.1.6 为基线。没有更新正式目录、两个交付 ZIP 或公网。

## 起飞和航行

起点改成文昌风格的滨海发射场：地面待发、垂直升空、穿越云层与大气、转向近地空间，随后进入地月系统。参考资料为[中国载人航天工程办公室文昌发射场介绍](https://www.cmse.gov.cn/gygc/xtzc/hnfscxt/)。场地建筑和海岸、飞船与起飞过程为科普示意，不是精确测绘或实际飞行导航。

飞船净空取自真实网格包络并随当前模型缩放。实体星球、恒星、拉长天体与光环有独立安全范围；大气可以穿过。自动航线用避障航段和通过安全验证的圆角连接，手动移动使用整段扫掠检测。发射场的大设施采用实体包络，三层发射台采用扩大后的局部碰撞盒。驾驶舱视点和跟随相机分别检查净空。

爬升中切换目的地会继续升空并更新目的地；手动接管后继续起飞只使用剩余较高航点。W/S 等移动键能立即接管自动航段；异步目的地准备期间的手动指令可取消等待中的切层。加载或航线规划失败保留上一场景。

## 视觉和渲染

- 船体增加面板、舱罩、金框、散热器、起落架和仪表屏，静态零件按材质合并。驾驶舱转头与外部船体的朝向分开处理。
- 星空包括固定屏幕像素尺寸的星点、银河辉光和暗尘带。高配置背景 27,000 星点，低线程设备 13,000 星点；地表白昼到太空逐步显现。
- 星球共享三档球面几何：36×24、80×48、160×96。近景提高球面精度，远景减小几何负担；保留已有本地纹理并提高各向异性过滤。
- 移除旧 26 ms 帧间隔节流。世界与驾驶舱提前编译，重复使用相机计算对象，驾驶舱投影只在尺寸变化时更新，标签低频更新。
- 持续帧压力下自动降低画布像素负载，长时间顺畅后缓慢恢复；保持球面和船体拓扑。控制面板显示运行时帧间隔估计的 FPS。

## 验证范围

64 项逻辑测试与 Vite 构建通过。包括七层场景 800 多组天体间航线、真实船体所有顶点包络、发射场世界坐标变换、三层台面的整段碰撞、相机净空、质量调节，以及连续起飞、改目的地、手动接管、异步取消、错误恢复与资源释放。

状态测试使用纯 Node 渲染宿主替身，几何、相机与碰撞计算使用真实 Three.js 代码；没有开启浏览器、绘制 GL 像素或自动审核 UI。

静态计数：新版飞船为 13 次绘制、34,540 三角形；原版为 48 次绘制、9,928 三角形。驾驶舱由 31 次绘制降为 8 次。此处说明结构变化，不能替代实际设备 GPU/FPS 测量。实际视觉和流畅度等待用户人工预览。

NASA 公共目录快照、29 个太阳系天体和七层探索继续保留；科普模型的尺度压缩和未知表面说明见 [AR宇宙航行数据来源.md](AR宇宙航行数据来源.md)。
