# 星语第一版基线

确认日期：2026-10-10。用户确认当前网站作为第一版，项目版本号 `0.1.0`。

## 第一版内容

- 统一立体土星品牌标识、白色导航和大幅影像排版。
- 首页 NASA 月球之旅影片节选，以及孩子仰望天空、望远镜观星、星空三种摄影主题。
- 探索宇宙、星空图谱、AI 星语、观测指南、AR 宇宙云图、社区、知识卡、天文挑战、我的星空。
- 探索宇宙左上角知识卡入口；八大行星围绕太阳中心公转；真实坐标观测地与三维地形地图。
- 页面切换动画、按钮反馈、随滚动从下向上逐渐显现；星语快捷入口可移动、隐藏与恢复。

## 功能范围

AI 与知识卡使用本地知识演示，未接入真实大模型。AR 为科普影像与相机叠加演示，未实现实时天空对齐。社区讨论、评论、喜欢和个人收藏保存在当前浏览器，未连接账户或云端服务。地图采用真实底图与高程数据，未接百度城市三维建筑。

后续由用户人工审核。制作过程中标为“第三版”的素材、截图和记录保留原名，作为第一版形成过程的资料。
