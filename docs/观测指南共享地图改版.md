# 观测指南预览 · 0.1.5-preview.1

基线：已上线 0.1.4。用户要求先预览、人工审核，此版尚未发布公网。

## 用户可见变化

- 右侧常驻介绍栏取消，地图占满整行。
- 下方四张地点卡片负责定位，重复点击同一地点也可回到该位置。
- 点击地图的观测站名称，打开白色资料卡，包含发展历程、科普介绍、经纬度、参观提示及官方来源。支持关闭按钮、Esc、点击遮罩，保留减少动态效果偏好。
- 三张观测入门卡片整块可点击，分别打开月相、观星设备入门、夜间准备知识；可以收藏并继续问星语。
- 在线地标资料由公共服务统一提供；读取不需要登录。底图和真实高程由同一服务转发，避免每台访客电脑直接连接不同境外瓦片源。
- 加载中及网络失败时，展示随网页交付的真实地理轮廓与 WGS84 地标，仍可定位、打开资料卡；明确标注为备用地理图，不冒充详细道路地图或 3D 地形。

“共享”指所有访客能读取同一组公共地点与资料；各人独立移动自己的地图，不同步他人的拖动和缩放。没有添加用户发布地点、实时天气、实时天空或直播画面。

## 接口与部署

- `GET /api/observatories`：共享地点和资料版本。
- `GET /api/observatories/events`：SSE 初始资料快照、连接保活与自动重连。现有地点是经核查的只读目录，无后台编辑功能；资料发布更新后重连会读取新版。
- `GET /api/map/base/{z}/{x}/{y}.png`：OSM 可见底图瓦片。
- `GET /api/map/terrain/{z}/{x}/{y}.webp`：Mapterhorn Terrarium DEM。
- 后端只有固定白名单上游与数字瓦片地址；限定东亚视野、缩放范围、文件类型、2 MiB 大小、10 秒超时，不转发登录凭据。
- 保留底图与高程归属；设置可识别的 User-Agent、站点 Referer。按上游 Cache-Control 缓存；没有上游有效期时以 7 天缓存。Cloudflare 使用 Cache API，本机使用有界临时缓存；不预下载或抓取整片地图。

用户确认后，需要将 `backend/api.mjs`、`backend/observatory-api.mjs`、`backend/observatory-catalog.mjs` 同步到既有共享服务的 `community-api/` 并部署，然后将前端 `VITE_COMMUNITY_API_URL` 指向同一公网社区 API。所有适配器继续复用 `handleApi`，不修改社区账号数据库或媒体对象。不应把预览地址 `127.0.0.1` 构建进公网版本。

## 核查来源

- [MapLibre 3D 地形](https://maplibre.org/maplibre-gl-js/docs/examples/3d-terrain/)、[RasterDEM API](https://maplibre.org/maplibre-gl-js/docs/API/classes/RasterDEMTileSource/)。
- [OSM 瓦片政策](https://operations.osmfoundation.org/policies/tiles/)。代理不可保证外部服务永远可用，因此保留明确降级和备用图。
- [Mapterhorn TileJSON](https://tiles.mapterhorn.com/tilejson.json)：Terrarium、512 像素、高程模板；原地标坐标来源见 `地图数据来源.md`。
- [Natural Earth 陆地 GeoJSON](https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson)、[公有领域许可](https://www.naturalearthdata.com/about/terms-of-use/)。只绘制陆地轮廓，不绘制行政边界。
- 场馆发展史引用链接位于共享目录与每张资料卡中。新增两张入门知识卡引用 NASA Skywatching 官方资料；主题配图沿用已有 Pexels 素材。

## 本次验证

构建通过。12 项针对共享目录、多访客一致性、SSE 取消、瓦片参数边界、凭据隔离、缓存、上游失败以及既有坐标和知识逻辑的检查通过。实际请求本机共享服务的目录、OSM 底图和 DEM 均返回 200。没有运行自动 UI 审核，界面由用户人工审核。
