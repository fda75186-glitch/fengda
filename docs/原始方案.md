## 二、功能模块（7 大模块）

| # | 模块 | 功能点 | 演示看点 |
|---|---|---|---|
| 1 | **AI 天文助手「星语」**（核心） | 多轮问答（DeepSeek）、语音提问、预设热门问题引导（"黑洞里面是什么？""太阳还能烧多久？"）、回答附带知识卡片链接、打字机流式输出 | 现场连续问 2-3 个问题，展示多轮对话+语音 |
| 2 | **AI 生成科普卡**（差异化亮点） | 输入主题 → AI 自动生成图文科普卡（标题、简介、3-5 个知识点、趣味冷知识），可保存收藏 | 现场输入"木星大红斑"，AI 当场生成卡片——最打动评委的一幕 |
| 3 | **知识图谱/可视化**（差异化亮点） | 太阳系行星对比图（大小/温度/周期）、恒星生命周期流程图、宇宙 138 亿年时间线、天体距离可视化（均用 ECharts） | 行星对比图和恒星演化图，视觉冲击强 |
| 4 | **科普内容库** | 分类：太阳系/恒星/星系/黑洞/探索史/天文观测；图文卡片+视频嵌入；搜索、筛选、热门排行 | 内容量大、分类清晰 |
| 5 | **互动测验** | 天文知识小测验（选择/判断）+ AI 解析每道题 + 排行榜 | 增加互动性 |
| 6 | **每日天文推荐** | "今日天文"每日推荐一个天体/现象 + 根据浏览记录个性化推荐 | 体现"智能" |
| 7 | **用户系统+社区** | 注册登录（JWT）、收藏打卡、讨论区发帖评论、个人主页上传天文摄影、管理后台 | 获奖标配，完整性加分 |

## 三、页面结构（11 个页面）

1. **首页**：今日天文 + 六大板块入口 + AI 悬浮窗
2. **科普内容列表页**：六大板块分类筛选（宇宙起源/太阳系/恒星世界/深空天体/人类探索史/天文观测入门）
3. **内容详情页**：图文 + 视频嵌入 + 点赞收藏
4. **AI 助手对话页**：多轮问答 + 语音输入 + 流式输出
5. **AI 生成科普卡页**：输入主题 → 生成卡片 → 收藏
6. **可视化图谱页**：行星对比图 / 恒星演化流程图 / 宇宙时间线
7. **天文地图页**：Leaflet 中国天文台/著名观测地 21 点位
8. **测验页**：选择题 + AI 解析 + 排行榜
9. **论坛页**：列表 + 详情（发帖/评论/点赞，含"摄影分享"标签）
10. **个人主页**：我的天文摄影作品、收藏、发帖、观测记录
11. **管理后台**：管理用户/帖子/评论/卡片 + ECharts 数据概览

## 四、技术架构

```
用户层      PC 浏览器 / 移动端（浏览、语音提问、互动）
                ↓ HTTPS
前端层      Vue3 + Vite
            · Element Plus（组件库，少写 CSS）
            · ECharts（可视化图谱）
            · Axios（请求）
            · Web Speech（语音输入）
                ↓ JSON API
后端层      Python FastAPI
            · 业务接口（内容/社区/测验/卡片/后台）
            · JWT 用户认证
            · AI 代理（DeepSeek 密钥不暴露前端）
                ↓
数据层      SQLite
            · users / articles / ai_cards / conversations
            · posts / comments / favorites / quiz_questions
            · works / observatory_points / admin_logs
                ↓ 调用
外部服务    DeepSeek API（AI 问答/生成）· NASA 图片素材 · B站科普视频嵌入
```

## 六、素材来源（不用自己造内容）

## 九、风险与对策

| 风险 | 对策 |
|---|---|
| AI 答错天文知识（幻觉） | 页面加"内容仅供参考"声明；热门问题预置人工校验的答案缓存 |
| 演示现场 AI 生成失败 | 演示前反复测试；准备 1-2 条缓存卡片兜底 |
| 图片版权 | 只用 NASA 公有领域图，不商用 |
| 内容工作量太大 | 每篇科普卡 300-500 字即可，用 AI 批量起草 + 人工核对 |
| 开发进度失控 | 功能优先级排序：AI 助手 > 内容库 > 可视化 > 测验 > 论坛 > 后台，保主干弃枝叶 |

## 十一、页面排版规范（参考豫见中原 + 陶韵智境）

### 核心排版逻辑（4 条）

1. **先空间后细节**：星空导览/轮播先建立整体认知，再进详情——不做纯列表堆砌
2. **左右分栏联动**：星空画布+右侧详情栏、侧栏+内容区，交互感强
3. **顶部 tab 拆主题**：内容多就用 tab 分类（六大板块），页面清爽
4. **图片优先、卡片化**：所有列表页统一卡片网格，图片大文字少

### 各页面排版设计

| 页面 | 借鉴来源 | 排版设计 |
|---|---|---|
| 首页 | 豫见·首页 | 导航 → NASA 全屏轮播 → 六大板块卡片 → 今日天文 → AI 悬浮球 |
| 星空导览页 | 豫见·地图页 | 搜索框 + 主区 3D 星空 + 右侧详情栏（点击天体联动显示+收藏） |
| 科普内容页 | 豫见·地方文化 | 顶部 tab（六大板块）→ 轮播推荐位 → 卡片网格 |
| 内容详情页 | 两作品通用 | 大图头图 → 正文 → 冷知识框 → 相关推荐 |
| AI 助手页 | 豫见·智能策划 | 左侧历史记录 + 右侧对话流（流式输出）+ 底部输入栏（文字/语音） |
| 个人中心 | 豫见·个人中心 | 星云背景 + 观星等级吊牌 → 收藏/AI历史/观测记录 tab |
| 管理后台 | 豫见·后台 | 左侧导航 + 表格增删改查 + 宇宙数据看板 |

### 三个关键页面线框（示意）

**① 首页**
导航（Logo ｜ 首页 板块 星空导览 测验 论坛 个人中心）→ NASA 全屏轮播 → 六大板块入口卡片（一行 3 个 × 两行）→ 今日天文/热门内容预览 → 右下角 AI 悬浮球

**② 星空导览页（借鉴豫见地图页的"左图右栏联动"）**
顶部搜索框（搜天体）→ 主区 3D 星空画布（占宽 2/3，Three.js）→ 右侧详情栏（天体信息 / 知识卡链接 / 收藏按钮）→ 底部"今日推荐天体"横条

**③ 科普内容页（借鉴豫见地方文化的"tab + 卡片"）**
顶部 tab（宇宙起源｜太阳系｜恒星｜深空｜探索史｜观测）→ 精选科普卡轮播位 → 卡片网格 3 列（图 + 标题 + 收藏按钮）
